# U.S. promotional image assets

Date: 2026-11-01

## Delivery and generation mode

Created with the built-in image generation tool in generation mode (`ads-marketing`). No CLI/API fallback was used. The existing Canada dashboard, sports and cinema artwork was inspected to establish the requested premium home-theater collage style. The final successful images are original U.S. compositions generated from text, with navy/red lighting, U.S. skylines and a star/play emblem. They are not modified Canada assets.

All artwork uses the exact brand **IPTV USA 8K**, without a domain, phone number, price, availability guarantee or resolution guarantee. The sports image adds **SPORTS**; the cinema image adds **MOVIES & SERIES**. “8K” is used as part of the brand name only.

The initial three reference-based requests using real broadcaster marks and existing movie/series poster concepts were rejected by the tool safety system at the output stage, with category `other`. No outputs were returned for those requests. The delivered alternative uses original fictional genre imagery and generic channel/sport category tiles. It therefore does not fulfill the requested real broadcaster/movie-logo component; no such logos or specific title availability should be inferred from these assets. Existing illustrative/availability context should remain on the pages.
